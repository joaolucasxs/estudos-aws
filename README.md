# Estudos AWS

Anotações, resumos e laboratórios práticos da minha formação em cloud:
**AWS re/Start** e **Tech para Todos** (Escola da Nuvem) e preparação para a certificação **AWS Certified Cloud Practitioner (CLF-C02)**.

Escrevo tudo com as minhas palavras, como material de revisão. Os labs são feitos no Free Tier da AWS e documentados com prints.
